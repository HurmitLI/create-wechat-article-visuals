## 1. 默认视觉系统

适合 AI、Agent、开发者工具和科技产品深度稿的默认方案：

| 角色 | 颜色 | 用法 |
|---|---|---|
| 背景 | `#FAF8F4` | 大面积暖白底，避免纯白刺眼 |
| 正文 | `#2E2E31` | 标题、说明和主线 |
| 主色 | `#5C6FA3` | 系统节点、路径和品牌词 |
| 强调 | `#C9633F` | 冲突、关键转折、唯一重点 |
| 辅助 | `#AAB5CE` | 次要路径、边框和注释 |

使用少量纸张颗粒或轻微手绘边缘增加编辑感。不要叠加霓虹光效、玻璃拟态、复杂渐变和写实 3D。

## 2. 图片类型选择

- 有明确步骤：流程图或闭环图。
- 有多个对象且可用相同维度评价：并列对比图。
- 有组件、控制权或信息流：架构图。
- 有两种工作方式：左右前后对照图。
- 有抽象矛盾或情绪：编辑插画。
- 有数值和趋势：基于可靠数据的图表；没有数据时不要伪造坐标轴。

一张图只承载一个主结论。信息图最多保留 5–7 个主要节点；复杂关系拆成两张图。

## 3. 封面构图

- 比例：约 2.35:1。
- 标题区占宽度约 35%–50%，四周留足安全边距。
- 标题推荐 2–4 行，断行按语义，不孤立单个标点。
- 视觉主体与标题形成左右或中心辐射关系，不相互覆盖。
- 小尺寸预览时，标题、主体和一个强调色仍应清楚。
- 副标题不是必需；不要在封面堆叠正文摘要。

若生成式模型无法稳定输出中文标题：

1. 先重试一次，简化画面和文字；
2. 仍失败时生成无字底图；
3. 另做 SVG 精确文字层或交付排版参数；
4. 明确标注哪些文件是底图、哪些是成品。

## 4. 正文信息图

- 比例优先 3:2 或 16:9。
- 画布宽度至少 1200 px；SVG 使用明确 `viewBox`。
- 文字层级不超过三级：图题、节点名、短说明。
- 节点名尽量不超过 8 个汉字，说明尽量不超过 18 个汉字。
- 连线方向保持一致，箭头不要穿过文本。
- 颜色既要表达关系，也要有形状、标签或线型作为冗余编码。
- 在底部保留一句图注位置，但不要把长段正文塞进图里。

## 5. Prompt 结构

按以下顺序写生成式图片 Prompt：

1. 使用场景与比例；
2. 一句话主题；
3. 画面空间关系；
4. 必须出现的元素；
5. 标题原文和语言要求；
6. 风格、颜色、材质；
7. 明确禁用元素；
8. 可读性与留白要求。

示例骨架：

```text
为中文科技微信公众号生成约 2.35:1 横版封面。主题是【核心判断】。
左侧保留标题区，右侧呈现【视觉主体】；【对象 A】通过【关系】连接到【对象 B】。
标题必须准确写作：『【标题】』。使用简体中文，英文产品名大小写准确。
采用克制的编辑插画风，背景【颜色】，主色【颜色】，强调色【颜色】。
避免【机器人脸、芯片、代码雨、品牌 Logo、复杂小字】。
缩略图状态保持标题清晰，画面有大面积留白。
```

## 6. 常见失败与修复

- 文字错误：减少文字量；把解释移出图片；重试或改用 SVG 精确排版。
- 图好看但没信息：重新写“一眼理解的结论”，删掉不支持它的元素。
- 图片风格不一致：复用同一颜色、线宽、圆角、纹理和人物设定。
- 手机端看不清：减少节点和说明，提高字号，拆成多张图。
- 信息图像流程图模板：加入与文章观点有关的空间隐喻，但不牺牲准确性。
- 品牌元素混乱：仅在正文确实比较品牌时出现准确文字，不生成近似 Logo。
